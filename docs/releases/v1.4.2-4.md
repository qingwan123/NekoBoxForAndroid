## 新增：VLESS Encryption（后量子加密层）

Xray 从 v25.8.31 起在 VLESS 内部加了一层后量子混合加密（ML-KEM-768 + X25519），
服务端启用后，旧客户端会直接断连且**没有任何日志提示**。上游 sing-box 目前没有实现。

本版补齐：

- 内核新增 `protocol/vless/encryption`（握手 / AEAD / native·xorpub·random 三种形态）
- App 新增独立的「VLESS 加密层」设置项；订阅里的 `?encryption=` 会自动读入，
  导出链接时也会带上
- 注意：它与 `flow`（xtls-rprx-vision）是两个独立参数，可以同时使用

已验证：配置解析与内核初始化通过（真实 1184 字节 ML-KEM 公钥），
实测节点可正常连接。上游参考实现只对 `native.0rtt` 做过真实服务器验证，
`xorpub` / `random` / `1rtt` 逻辑完整但未逐一实测。

## 内核升级到 sing-box 1.15.0-alpha.13

原来的内核 fork（MatsuriDayo/sing-box）已停在 1.14，本版改为**直接跟随 SagerNet 上游**，
fork 独有的 `nekoutils` / `boxapi`（约 16K）移植过来继续使用。

1.15 带来的主要变化：

- 自研 TCP/IP 栈，TUN 吞吐、功耗、内存全面改善（当前仍沿用旧 `stack` 选项）
- HTTP 代理重写：默认 HTTP/2、支持 HTTP/3 与 CONNECT-UDP
- 新增 MASQUE client/server、Tailcat、证书 SHA-256 钉扎
- NaiveProxy 更新到 154.0.8037.49-2

> 1.15 目前只有 alpha 版本，尚无 stable。

## 修复

- **启动失败 `open .../geosite:category-ads-all: no such file`**：切到上游时丢了 fork 里
  `geoip:` / `geosite:` 前缀的解析补丁，内置规则被当成文件路径去打开。已补回，
  并补齐了节点切换回调 `Selector_OnProxySelected`。
- 配置检查工具增加了规则集用例与 geo 钩子，这类回归以后能在打包前发现。

## 安装

仅 arm64-v8a，release 构建（R8），签名与之前版本一致，可直接覆盖安装。
若 1.15 alpha 出现稳定性问题，可回退到 `v1.4.2-3`（1.14 内核）。
