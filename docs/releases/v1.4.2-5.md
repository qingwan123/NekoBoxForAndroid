## 变更

- **启用 sing-box 1.15 的新 TCP/IP 栈**：生成 tun 入站时不再写 `stack` 选项。
  1.15 起 sing-tun 自带实现，官方称峰值吞吐、功耗、内存占用全面优于旧的
  gvisor / system 实现；旧选项自 1.15 废弃，将在 1.17 移除。
- **副作用**：设置里的「tun 实现」（system / gvisor / mixed）不再影响生成的配置，
  三项现在都走新栈。该选项保留在界面中，避免改动既有节点的配置结构。

## 已验证

- 不带 `stack` 的 tun 配置可被内核正常解析
- 带 `stack` 的旧写法仍可解析（仅废弃提示），不会因升级而无法启动
- 实机使用正常

## 安装

仅 arm64-v8a，release 构建（R8），签名与之前版本一致，可直接覆盖安装。
若新栈出现异常（个别应用连不上、DNS 异常等），可回退到 `v1.4.2-4`。
