连接代理后，底栏自动测一次当前节点的延迟。

## 新增

- **连接后自动测速当前节点**：状态栏不再停留在「已连接」，连接成功约 1.2 秒后自动发起一次连接测试，依次显示 `已连接` → `正在测试…` → `连接可用，XXX ms`。
  - 测的是当前节点的真实链路延迟（走 mixed inbound 请求测试 URL），不是本地 ping
  - 正在测速时不会重复触发；连接后立即断开的话，排队的那次不会执行
  - 测试地址沿用设置里的 `connectionTestURL`（默认 `http://cp.cloudflare.com/`）
